SCHATZSUCHE ONLINE V6.13.1 – UI-PATCH

Änderungen:

1. CHAT KOMPAKTER
- Chatfenster deutlich niedriger
- kleinere Abstände

2. MOBILE WERTEÜBERSICHT
Die obere Werteübersicht scrollt auf dem Handy nicht mehr horizontal.

- 3 Werte pro Zeile

- kein Links/Rechts-Wischen mehr nötig

Zusätzlich wurden auf Mobilgeräten:
- Spieltitel etwas verkleinert
- Metaangaben kompakter
